# Federico Ostan Bazan - Portfolio

A clean and modern portfolio website built with HTML, CSS, and JavaScript, using Bootstrap-like styling.

## Features

- Responsive design using Bootstrap-like classes
- Modern UI with smooth animations
- First-time visitor detection
- Clean and maintainable code structure
- Mobile-first approach

## Technologies Used

- HTML5
- CSS3 (with Bootstrap-like styling)
- JavaScript (ES6+)
- Bootstrap 5.3.0 (CDN)

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/fedeostan/fedeportfolio.git
```

2. Open `index.html` in your web browser to view the website.

## Structure

- `index.html` - Main HTML file with Bootstrap-like structure
- `styles.css` - Custom styles complementing Bootstrap
- `script.js` - Vanilla JavaScript functionality
- `intent.html` - Intent page (to be implemented)

## Features

- Responsive navigation
- Smooth animations and transitions
- First-time visitor detection
- Bootstrap-like components and utilities
- Mobile-friendly design
